Spécifications Techniques & Architecture (Pour Google Antigravity)3.1 Architecture de la Base de DonnéesPour s'adapter à l'existant sans régression, la table events doit intégrer un champ discriminant (type: ENUM('private', 'public')).sqlCREATE TABLE ticket_categories (
    id INT PRIMARY KEY AUTO_INCREMENT,
    event_id INT,
    name VARCHAR(50), -- VIP, Classique...
    price DECIMAL(10,2),
    capacity INT,
    sold_count INT DEFAULT 0,
    ai_background_url VARCHAR(255),
    FOREIGN KEY (event_id) REFERENCES events(id)
);

CREATE TABLE purchased_tickets (
    id INT PRIMARY KEY AUTO_INCREMENT,
    ticket_category_id INT,
    buyer_name VARCHAR(100),
    buyer_email VARCHAR(100),
    qr_code_token VARCHAR(255) UNIQUE, -- Token JWT signé ou UUID v4
    status ENUM('valid', 'scanned', 'cancelled') DEFAULT 'valid',
    scanned_at TIMESTAMP NULL,
    FOREIGN KEY (ticket_category_id) REFERENCES ticket_categories(id)
);
Utilisez le code avec précaution.3.2 Sécurité & Anti-Fraude du Contrôle d'AccèsCryptographie : Les QR Codes générés pour les billets publics doivent contenir un token cryptographique unique contenant l'ID du billet et une signature numérique serveur. Cela empêche la génération de faux QR codes hors de la plateforme.Idempotence du Scan (API Mobile) : L'endpoint de validation /api/v1/scan doit exécuter une transaction atomique (ACID) en base de données.Si status == 'valid' ➔ Passer immédiatement à scanned et enregistrer scanned_at.Si status == 'scanned' ➔ Renvoyer une exception HTTP 409 (Conflict) avec l'horodatage du premier scan pour bloquer les doublons.3.3 Stack Technique RecommandéeBackend API : Conserver la stack actuelle (Node.js / Laravel / Python) augmentée d'un SDK d'orchestration pour les appels de génération d'images.Génération IA : Intégration de l'API Imagen (Google Cloud Vertex AI) ou OpenAI DALL-E 3 pour assurer la génération d'images ultra-rapide par prompt.Traitement d'images : Utilisation d'une bibliothèque côté serveur (Sharp pour Node.js ou GD/Imagick pour PHP) pour fusionner dynamiquement le fond généré par l'IA et le QR Code unique de l'acheteur.4.
